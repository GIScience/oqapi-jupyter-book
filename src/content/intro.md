# Introduction

Welcome to the ohsome Dashboard tutorial!

**OpenStreetMap (OSM)** is an extensive database of user-generated, freely available geodata for
many applications.
However, varying data quality and a lack of standardisation can make it difficult to use.
That's why we built the **ohsome Dashboard**: so you can assess the quality of OSM data worldwide
or for specific areas and work out whether it meets your project's requirements.

:::{admonition} Dashboard URL
:class: seealso
https://ohsome-dashboard.heigit.org/en
:::

The ohsome Dashboard lets you analyse OSM data with a full version history - no programming
required. It generates statistics and visualises them directly, with customisable filters and
groupings by tags, types, regions and time.
The ohsome Quality API gives you access to information about the quality of OSM data for specific
regions and use cases.

:::{admonition} Analysing data quality in the ohsome Dashboard
:class: tip
1. Choose an analysis region
2. Choose an OSM data topic
3. Choose a quality indicator
4. Evaluate the result
